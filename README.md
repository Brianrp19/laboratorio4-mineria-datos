# Laboratorio 4 de Minería de Datos — UTN

El laboratorio consiste en realizar un análisis exploratorio de datos (EDA) con los CSV originales de Chinook utilizados en el Proyecto 1.

## Objetivos

- Examinar la estructura, los tipos de datos y las relaciones entre las tablas.
- Identificar valores faltantes, duplicados y otras inconsistencias.
- Resumir y visualizar las distribuciones y los patrones relevantes.

## Herramientas

Se utilizará Python en Google Colab, con pandas para explorar los datos y Matplotlib para visualizarlos.

## Estructura

- `datos/origen/` albergará los CSV originales de Chinook.
- `datos/procesados/` albergará los archivos generados durante el EDA.
